## Context

這是現有搜尋介面的局部調整。半星 label 的 hover 外框與手機截圖相符，但觸控後的實際狀態需瀏覽器驗證。評分標題及選項目前分別使用 flex，因此數值與重設按鈕沒有共同欄寬。使用者取消第 4 項刪除建議，主按鈕內外及其下方文字全部保留。

## Goals / Non-Goals

**Goals:** 去除指定五段文案；半星觸控／滑鼠選擇無矩形殘留；評分文字與重設選項對齊；維持手機、桌面及鍵盤可用性。

**Non-Goals:** 不改動搜尋邏輯、API、評分值、類型選项、歷史紀錄、套件或後端。保留 EatThis、今天，吃什麼？、搜尋距離說明、主按鈕內目前條件、按鈕外定位說明、初始與操作狀態、錯誤及復原提示、結果資訊和頁尾。這項保留依據使用者明確修正，不受截圖裁切範圍影響。

## Decisions

### 移除半星 hover 外框並保留鍵盤焦點

在 rating-half 移除 hover outline；保留原生 radio、accessible name、checked 與 focus-visible，不使用 blur 或隱藏所有 outline。替代方案僅限制 hover 到滑鼠媒體查詢仍會保留使用者不需要的方框，因此不採用。以真實手機觸控確認選取後沒有殘留框，鍵盤進入控制項仍可辨識焦點。

### 評分文字與重設選項共用右側欄

在 rating-control 的內容層使用共用欄位：上排最低評分標示與右側 rating-value，下排五顆星與 rating-unrestricted。保留 fieldset/legend 的語意，依需要將 legend 保持獨立而讓文字與按鈕共用內容 grid 的右欄。右欄以 max-content 或共同內在尺寸決定欄寬，文字靠右、按鈕填滿，文字盒與按鈕外框左右邊界一致（容許 1 CSS px 誤差）。不以不同 margin 補齊，也不量測文字後寫死寬度。

右欄需容納 0.5 星以上至 5 星以上及不限評分，按鈕文字不折行，最小高度 44px。若可用寬度無法容納五顆星與右欄，右欄整組移到下一排並靠右；星列完整保留、每半星至少 24px 寬及 44px 高。允許依佈局需求使用局部容器查詢，不縮小點擊目標。

### 精準刪除五段文案並保留動作區文字

從 App.vue 移除 proposal 列出的五段文案，移除頁首孤立 brand-rule 與僅服務刪除內容的樣式及間距。移除 rating-help、category-help 的可見節點時同步清理對應 aria-describedby，維持 legend 及各選項名稱。不要改動 action-detail、action-note、state-panel、footer-note 或 stateCopy；其文字及顯示時機維持既有行為。同步 DESIGN.md 與介面方向文件的 hover／說明文案描述。

## Implementation Contract

- 範圍：nearby-food-selection 的前端顯示、可存取性引用及對應回歸驗證；不修改後端與 request/response 結構。
- 資料：selectedMinRating 仍為 null 或 0.5 至 5 的半星值；變更控制項不觸發 geolocation 或 pickNearbyFood。
- 行為：第五顆星左半選 4.5，填滿四顆半黃星，顯示 4.5 星以上；不限評分設為 null，五顆星灰色。觸控及滑鼠不顯示半星 hover 方框；鍵盤保有可见焦點。
- 保留：主按鈕仍顯示目前條件，初始 state-panel 仍顯示準備好了提示，定位、查詢、無結果、權限拒絕、供應商失敗、限流及成功結果維持既有顯示。
- 自動驗收：App 測試驗證五段文案不存在、既有保留文案存在、語意名稱與半星選取／重設正確、修改評分不呼叫定位與 API。沿用既有非同步狀態測試，不新增鏡像 CSS 的字串測試。
- 視覺驗收：在 320、390、768、1280 CSS px 檢查無水平溢出、右側欄對齊、文字不被裁切，覆蓋 null、0.5、4.5、5；手機觸控後無殘留框，桌面鍵盤焦點可見。390px 寬度以 4.5 星以上文字盒與不限評分外框同寬且右緣重合為範例。
- 驗證工作目錄為 F:/Website/EatThis/src/EatThis.Web；執行 package.json 中 test:run、typecheck、build。記錄 DOM 測試與實際瀏覽器結果的差異，瀏覽器不可用時將視覺／觸控項目明確列為未驗證。

## Risks / Trade-offs

- [觸控 hover 與 focus 混淆] → 手機確認觸發來源，不因視覺修正移除鍵盤焦點。
- [320px 容不下星列與右欄] → 右欄整組換行，維持點擊目標，不壓縮星星。
- [刪除說明後 ARIA 引用失效] → 清理失效引用，保留選項名稱與群組標示。
- [誤刪第 4 項文案] → 在 App 回歸測試明確斷言目前條件、定位說明、初始提示與頁尾存在。

## Migration Plan

僅前端建置部署，不需要資料遷移或後端部署。回滾為還原本變更的前端模板、樣式及相應產物；不得手動修改雜湊資產。設計文件隨實作同步。
